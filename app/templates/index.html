Better charts
  • No more third-party downloads: The dashboard's chart library now ships with the app itself, so charts load without reaching out to an external server.
  • Categories keep their colors: A category now gets the same color every visit — it no longer changes as categories come and go, and the Expenses / Income views color consistently too.
Readable amounts
  • Thousands separators everywhere: $12345.67 now reads $12,345.67 — on the dashboard, History, accounts, goals, and everywhere else money shows.
A tidier sidebar + an always-there Add button
  • Grouped navigation: The sidebar's flat list is now organized into Money, Plan, and Setup groups so the right page is easier to find.
  • Add from anywhere: "Add transaction" moved out of the sidebar into a persistent Add button — top-right on desktop, a floating button on your phone.
  • Less clutter: Change password now lives on the Profile page.
Collapsible charts
  • Less scrolling: The dashboard's chart section folds away — open by default on desktop, tucked behind a tap on your phone.
